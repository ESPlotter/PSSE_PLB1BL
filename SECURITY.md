# Security policy

Please report suspected security issues privately to [support@esplotter.com](mailto:support@esplotter.com). Do not publish details in a public issue or pull request before the maintainers have had a chance to review them.

Include the affected version, a concise description, and steps to reproduce when safe. Do not send credentials, customer grid models, or other confidential data. ESPlotter will acknowledge the report and coordinate any disclosure with the reporter; no response-time commitment is made by this policy.
