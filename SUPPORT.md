# Support

For project questions, report issues, or request help, contact [support@esplotter.com](mailto:support@esplotter.com). Use GitHub issues for reproducible bugs and feature requests once the public repository is available.

When asking for help, include:

- The `LPB1BL` package version and PSS/E version.
- The Python version used to run the example, if relevant.
- The steps to reproduce the issue and the expected and actual results.
- A short, sanitized log excerpt when useful.

Do not send PSS/E installation files, Siemens manuals, credentials, or confidential network data. Replace private case details with a minimal example where possible.
